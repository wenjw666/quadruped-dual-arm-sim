# QDA V2 · 产品演示审片版

- 观众：评审仿真平台、准备复现实验的机器人研究与工程人员。
- 承诺：用一段任务看懂语义入口、计划、运动、视觉闭环与结果追踪如何协同。
- 机制：受限语义提案 → 有状态的技能序列 → 控制租约 → 实际动力学与传感反馈。
- 下一步：验收本地视频；确认后才把视频入口挂到仓库 README。

画面方向：白底技术工作台，深色数据面板；橙色表示任务，青色表示反馈，绿色只表示已验证的终态。
1920×1080、30 fps、中文配音及字幕。镜头内容以实际传感器画面、实际状态重放、代码定义的地图和实测数据为依据。
UI 信息图明确标注为“接口结果重绘”，不是声称已经存在的产品操作界面。
机器人绕拍是模型展示；姿态重放标明来自实测关节与真值 odom；时长压缩注明时间重排。

镜头顺序：机器人亮相 → 本体及四相机 → 离线语音/本地模型 → 四步 Mission → 场景与导航 →
RL 台架动作 → 双腕视觉闭环 → 实测误差 → RViz/反馈 → 取消与拒绝 → 双后端 → 能力边界。

V1 虚拟抓放不作为 V2 物理抓放；近零距离到点不作为长路线验收；合成语音测试不作为真人识别率。
历史 RL 台架录像与新一轮工厂 Mission 分开标识。不使用第三方宣传片或生成机器人动作。
镜头库选择：采用 command-to-result / data pipeline 的因果布局，自行实现横版组件。
