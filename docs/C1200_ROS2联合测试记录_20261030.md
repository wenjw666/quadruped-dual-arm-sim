## 当前联调边界

本轮尚未形成“Docker 仿真节点直接发现板端 ROS 节点”的 DDS 联调。板端默认多播配置下只能看到板端自身节点；容器内的 ROS2 图查询在 Docker Desktop NAT 网络中无法完成发现。原因是容器位于 Docker/WSL 私有网段（`172.18/16`、`172.19/16`，host 模式也使用 Docker Desktop VM 地址），而板端只有 `192.168.1.0/24` 路由；DDS participant locator 和多播报文没有直达同一物理网段。

因此，本轮保留了仿真进程和板端节点运行状态，但没有向任何真实执行器发送控制命令。下一轮应优先让仿真 ROS2 进程运行在能获得 `192.168.1.x` 地址的环境中（Docker mirrored/host networking 或 WSL mirrored networking），再复用本记录中的 `ROS_DOMAIN_ID=8`、CycloneDDS 和 QoS 配置进行直接发现验证。
