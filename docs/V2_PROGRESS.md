# 第二版实施状态（2026-10-26）

开发分支 `v2/decision-rl`，基线 `v0.1.0-foundation`。当前已进入原工厂工程的实验性 RL 接入与感知接口阶段，完整方案尚未验收。

## 已实现并验证

1. 完整 B2 + 双 Aubo 自由基座动力学实验入口：重力补偿关闭，30 个限力矩执行器，PD 推进物理，夹爪 mimic 约束和机器人自碰撞。腕部单凸包造成的假穿透通过 CoACD 分解处理；分解有近似误差，不等于所有操作姿态已验证。
2. 动力学审计通过：自由落体 0.2 秒下降 0.198162 m；10 秒 PD 站立最低高度 0.502247 m、最大倾角 0.016438 rad，无初始穿透、采样自穿透或力矩越限。模型质量 85.665 kg。增益用于本地模型，未作硬件标定。
3. 隔离的 CPU PPO 训练验证：8192 步，确认优化器更新、checkpoint 保存/重载；5 个独立种子各 10 秒站立未跌倒。只验证训练链路，不证明行走、抓放或板端部署达标。
4. 任务协议 `PickPlace.action` 已生成构建；决策核心具有任务幂等、数据新鲜度、阶段超时、有限重试、持物取消、释放后条件与 2 cm 最终判据。搬运阶段允许底盘移动，到达后必须停稳才能放置。命令租约为纯逻辑接口。10 项测试通过。
5. 原版开源 B2 策略：固定版本及 SHA-256 下载、45 维观测和关节顺序适配、独立 MuJoCo 测试入口。3 项契约测试通过。完整模型 21 次短时运控测试均未跌倒，但低速/侧移跟踪未通过。官方裸机模型的另 21 次移植探针均触发终止，仍需核对上游执行配置，不能将其视为成功复现。
6. 修改模块通过 Python 编译检查，已有跟踪文件通过 `git diff --check`（只有 Windows 行尾提示）。
7. 已完成 65,536 步开源 actor 初始化 PPO 微调，但低速评估没有有效改善；已保留结果。另完成原版 RL 的指令响应校准和接触运动学速度反馈，63 个对照回合均未跌倒，前进速度误差从约 0.147 降至 0.055 m/s，仍有侧移和偏航耦合问题。
8. ONNX 与 PyTorch 在 1,000 个实际观测上的最大输出差约 1.91e-6。独立 `/v2` ROS 运控入口已接通真实关节状态、过期指令归零和故障锁存；原始和校准模式均通过消息测试。已生成 16 秒实际动力学连续预览。
9. 5 个新种子 × 7 种指令的 35 回合小幅双臂运动/随机载荷验证全部完成，无跌倒或非足端异常接触，最大机身倾角约 4.48°。这不替代全幅操作与完整抓放验收。

10. RL/ONNX + 自由基座 PD 已接入原工厂节点、同一地图、Nav2、双臂控制器和 RViz。新增唯一 `/cmd_vel` 仲裁节点；Smac 2D 替换 V2 的 NavFn，MPPI 速度上限收紧。机身 C0 和双腕相机已输出真实渲染图像；MoveIt 点云 OctoMap 已接入。详细验收范围见工厂接入记录。
11. 2026-10-26：本地 SmolVLM-500M Q8 + 投影器、Vosk 中文离线 ASR、SAPI 文件 TTS、MCP 工具桥和真实技能 ActionServer 已部署。双腕 ArUco/PnP IBVS 通过 MoveIt Servo 接入物理关节控制，两臂分别从 21.90/23.34 px 收敛到 1.42/0.93 px。任务幂等、取消、过期场景、控制互斥和能力门控已测试。语音四条短句通过三条；模型十二项通过十项，尚不能自主决策运动。见 [本地大脑部署](V2_BRAIN_DEPLOYMENT.md)。
12. 同日继续：Mission 有界计划、技能会话、底盘租约、腕部令牌心跳与命令独立超时、取消确认和模块新鲜度已接通。修复导航 map/odom 不一致、慢渲染阻塞控制锁和服务排队。真实四步 handoff、四步双腕视觉任务通过，双腕从 21.87/23.42 px 降至 1.42/0.72 px；KLT 短时过渡以合成图像验证。参见 [协同验收](V2_COORDINATION.md)、[整体结构](CODE_ARCHITECTURE.md)。

## 实验入口

- `run_v2_training.ps1`：构建训练模型 → 审计 → 小规模 PPO 验证。
- `start_brain.ps1 -WithSimulation`：本地模型与带大脑的 MuJoCo；`run_sim.ps1 -Brain -ServoFixture -Manual -Background` 启动独立视觉验收场景。
- `run_sim.ps1 -Background`：原工厂场景中的实验性 RL + Nav2 + MoveIt + 四相机 + RViz；默认不自动抓放。`-MotionMode kinematic` 返回 V1 对照。
- 容器 `python3 /ws/scripts/fetch_b2_reference.py`：取得固定 B2 权重与配置。
- 容器 `python3 /ws/scripts/evaluate_b2_reference.py`：在当前整机动力学模型运行原版 B2 策略。
- `run_v2_rl_bench.ps1`：实际 ROS 2 + ONNX 运控实验；详见本轮适配文档。
- 具体环境加载、模型对照及数据路径见 B2 核查文档。所有结果都保留 `runtime_ready=false`，直到速度跟踪与载荷测试通过。
