# C1200 相机选型与接入建议

本文把淘宝采购分成两条链路：先用 USB/UVC 验证 SmolVLM、ROS 2 和消息链路，再用 GMSL2/CSI/ISP 验证 RC12 原理图对应的产品路径。淘宝商品页面经常更换，采购时应以型号、传感器、串行器和接口照片核对，不能只按标题购买。

## 结论

| 优先级 | 推荐型号/搜索词 | 链路 | 用途 | 主要风险 |
|---|---|---|---|---|
| 1 | **Intel RealSense D455**（`RealSense D455 原装`） | USB-C 3.1，UVC/HID | 第一周 RGB/Depth/IMU、SmolVLM 和 ROS 2 验证 | 需要 USB 3.x 线缆和足够供电；librealsense/ROS wrapper 需在板端 ARM64 编译或安装 |
| 2 | **IMX390C-5200-GMSL2**（`IMX390 MAX9295A GMSL2 FAKRA`） | GMSL2 → MAX96712 → CSI-2 → ISP | 量产 RGB、HDR、室外/运动场景 | 卖家可能更换 serializer、输出格式或 FAKRA 规格；必须索要设备树和 Linux 驱动 |
| 3 | **SG2-AR0233C-GMSL2**（`AR0233 MAX9295A GMSL2 PoC`） | GMSL2 → MAX96712 → CSI-2 | 低成本 1080p RAW12 量产验证 | RAW12 需要 ISP pipeline 和 sensor tuning；单买摄像头不能证明 C1200 已支持 |
| 4 | **RealSense D457 GMSL/FAKRA**（`D457 GMSL FAKRA MAX96712`） | GMSL2/FAKRA，带 RGB/深度/IMU | 需要深度且最终希望走车载线束 | 必须有兼容 MAX96712 解串器和专用驱动；USB 模式可像 D455 工作，但不等于 GMSL 模式可直接使用 |
| 5 | USB UVC **IMX296/OV9281 全局快门工业相机**（`USB UVC IMX296 Linux`） | USB 2.0/3.x UVC | 低成本运动、延迟和 ROS 图像话题测试 | 多为单色；具体分辨率、帧率和格式取决于桥接板固件 |

## USB/UVC 路径：先验证 SmolVLM

### D455

官方规格为 RGB 1280×800@30、深度最高 1280×720@90、全局快门、BMI055 IMU、USB-C 3.1；理想距离约 0.6–6 m。官方页面：

- https://www.realsenseai.com/cn/products/d455/
- https://www.realsenseai.com/products/real-sense-depth-camera-d455f/

在 C1200 上的接入顺序：

1. 使用短的 USB 3.x 数据线，接板端 USB Host/Hub；先用 `lsusb`、`v4l2-ctl --list-devices` 检查枚举。
2. 先只开启 RGB 1280×800@15 或 30，将 RGB 转为 `sensor_msgs/msg/Image`，发布 `/camera/rgb/image_raw`。
3. SmolVLM 只消费 RGB；深度、IR 和 IMU 单独发布，避免第一阶段把 USB 带宽和 CPU 压力同时推高。
4. 再按需要加入 `realsense2_camera` 的 depth/IMU 流，并记录 USB 带宽、CPU 和内存。

D455 的 RGB 数据在相机内部完成采集/格式化后通过 USB 传输，主机路径是 xHCI/UVC/HID，不经过 RC12 的 MAX96712、MIPI CSI 和 ISP。这样适合快速验证模型与 ROS 节点，但不能验证 GMSL 线束、CSI lane、ISP tuning 或多相机同步。

淘宝上有 D455 的具体代购条目（商品 ID `559810621351`），但链接和店铺可能变化；搜索时使用完整型号并核对外壳、序列号、USB 线和保修。不要把 D456/D555 等标题相近的产品当作 D455 购买。

### 低成本 UVC 全局快门相机

可搜 `USB UVC IMX296 全局快门 Linux` 或 `USB UVC OV9281 120fps`。例如 NLK-1MP04 产品页列出 1/4 英寸单色全局快门、1280×800、USB 2.0/UVC、Linux 支持，720p/1280×800 可达约 120 fps：

- https://www.sznlk.com/product_view_268_271.html

该类相机适合测试图像时间戳、ROS QoS、运动模糊和端到端延迟，不适合作为 SmolVLM 最终 RGB 传感器，除非购买彩色 Bayer 版本并确认板端能处理其格式。下单前要求卖家提供 `v4l2-ctl --list-formats-ext` 输出、YUYV/MJPEG 是否可用、USB 供电电流和 ARM64 Linux 示例。

## GMSL2/CSI/ISP 路径：对应 RC12 原理图

### IMX390C-5200-GMSL2

可核验的产品页列出 Sony IMX390 2.12 MP、1920×1080@30、HDR/LFM、YUV422 8-bit、MAX9295A serializer、GMSL2、9–16 V PoC、12 V 下小于 250 mA、FAKRA 接口：

- https://fpgaintel.com/products/961

它更适合先验证“解串器输出已经是 YUV422、ISP 负担较小”的 RGB 方案。采购时必须确认：

- serializer 确实为 MAX9295A，GMSL 速率为 3/6 Gbps；
- FAKRA 是哪种 Z-code/连接器，线缆长度和屏蔽要求；
- PoC 电压/最大电流，以及是否需要单独 12 V 供电；
- 输出是 YUV422 还是 RAW12，I2C sensor 地址和 serializer/deserializer 地址；
- C1200 的 MAX96712 device-tree、lane 数、CSI virtual channel 和 ISP profile 示例。

### AR0233 GMSL2

同一产品页列出 `SG2-AR0233C-GMSL2`：AR0233 2.6 MP、1920×1080@30、RAW12、MAX9295A、GMSL2、9–16 V PoC、12 V 下小于 200 mA、FAKRA。RAW12 能更贴近 ISP 输入，但必须先完成 sensor mode、曝光/增益、Bayer order、CSI data type 和 ISP tuning，不能期望插上就出现 `/dev/video*`。

如果淘宝卖家没有上述 SG2 料号，可用两个可核验的同类料号反向询价：`LI-AR0233-GW5400-GMSL2-xxxH`（Leopard Imaging，AR0233AT + GW5400，YUV，MAX9295A/B，1920×1080@60，FAKRA Z，9–19 V）和 `STC-AR0233C-5200-G2A`（Supertek，AR0233 + GW5200，YUV422，1920×1080@30，MAX9295A，9–16 V PoC）。它们是产品规格参考，淘宝页面仍需逐项核对实际 serializer、输出格式和线缆。

### RealSense D457

D457 是 GMSL/FAKRA 的深度相机，适合最终需要 RGB+深度+IMU 的车载布线；官方页面：

- https://www.realsenseai.com/products/d457-gmsl-fakra/

它不是“接入 FAKRA 就等于 D455”。官方支持说明要求兼容的 GMSL deserializer 和专用驱动；D457 也可以切到 USB 模式，此时可按 D455 类 USB 路径验证：

- https://support.realsenseai.com/hc/en-us/community/posts/29655890628371-Realsense-D457-needs-any-additional-equipment-to-work?page=1

若使用 RC12 原理图中的 MAX96712，先确认 C1200 的 MAX96712 配置是否支持 D457 所需的 GMSL link、I2C pass-through、virtual channel、CSI lane 速率和 RealSense host driver。Jetson 的 MAX96712 overlay 不能直接复制到 C1200。

## 与 RC12 的关系

Linux 的 MAX96712 binding 说明该器件把最多 4 路 GMSL1/2 转成 CSI-2，每路 GMSL2 可为 3/6 Gbps：

- https://github.com/torvalds/linux/blob/master/Documentation/devicetree/bindings/media/i2c/maxim,max96712.yaml

因此，GMSL2 相机的典型数据路径是：

`sensor → MAX9295A serializer → FAKRA/GMSL2 → RC12 MAX96712 → CSI-2 → C1200 ISP → V4L2/GStreamer → ROS 2 → SmolVLM`

物理上“能接上”只代表线缆、电源和连接器相容；还需要 driver、device-tree、sensor mode、CSI/ISP profile、I2C 地址和时钟配置全部匹配。现阶段建议先购买一套 IMX390 或 AR0233 单路 GMSL2 模组、MAX96712 对端板/线缆和可调 12 V PoC 电源，不要一次购买四路相机。

## 采购验收清单

下单前向卖家索取以下资料并保存到项目资料目录：

1. 完整型号、sensor 和 serializer/deserializer 型号；
2. 分辨率、帧率、输出格式（YUV422/RAW10/RAW12）、Bayer 顺序；
3. GMSL1/2、3/6 Gbps、FAKRA Z-code、线缆长度和 PoC 电压/电流；
4. I2C 地址、寄存器初始化表、Linux ARM64 driver、device-tree 和示例命令；
5. 是否支持 MAX96712、CSI-2 lane 数和 virtual channel；
6. 触发/同步、温度范围、镜头焦距和畸变参数；
7. 退换条件：在 C1200 上无法枚举或输出指定格式时可退换。

## 推荐采购顺序

先买一台 **D455**，验证 USB RGB → ROS 2 → SmolVLM 和主机/板端分离通信；再买一套 **IMX390C-5200-GMSL2**（YUV422）验证 RC12 GMSL/CSI/ISP 主链路；如果需要 RAW/ISP 调优，再买 **AR0233 GMSL2**；如果最终明确需要深度和车载 FAKRA，再评估 **D457**，并把专用 host driver 和 device-tree 作为采购前置条件。
